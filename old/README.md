# Historical material

This directory preserves superseded plans, execution logs, migration drafts,
abandoned experiments and duplicate documentation from before the 2.0 release.
The original relative paths are retained beneath `old/` where practical.

These files are reference material, not maintained code or release documentation.
Do not run their scripts or treat their TODOs as the current implementation plan.
They are excluded from linting, test discovery and npm packages.

The maintained migration guide is [Migrating to 2.0](../docs/GUIDE/33-migrating-to-v2.md).
See [contributing](../docs/contributing.md) for current development commands.

`local/` contains ignored local tool history. It is neither tracked nor packaged.
The pre-runtime checkpoint is `f242aa5`; dependency removal is committed in `2b35f67`.
